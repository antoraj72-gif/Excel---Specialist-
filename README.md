# Excel Jarvis

Your smart offline Excel assistant for sales teams – an installable app for **Android, iPhone/iPad, Mac and Windows**.

**Open the app:** https://antoraj72-gif.github.io/Excel---Specialist-/

* The app is **encrypted**. It opens only with the access code – once on each device.
* **Install on a phone:** Android → Chrome ⋮ → *Install app*. iPhone/iPad → Safari → Share → *Add to Home Screen*.
* After the first open it works **without internet**. Your sales files stay on your own device – nothing is uploaded.
